# 🎤 소리 비행 (Sound Flight)

목소리로 조종하는 브라우저 게임입니다. **크고 높은 소리를 내면 위로**, **작고 낮은 소리를 내면 아래로** 움직이며 앞으로 나아가고, 장애물 사이의 구멍을 통과해 골인 지점까지 가면 됩니다.

HTML 파일 하나로 동작하며, 별도의 설치나 서버가 필요 없습니다.

## 플레이 방법

- **마이크 켜고 시작하기** → 브라우저의 마이크 권한을 허용하면 목소리로 조종할 수 있습니다.
- **비행기 고르기** → 프로펠러기 · 제트기 · 종이비행기 · 로켓 · UFO 중에서 선택합니다. 고른 비행기는 저장되고, 단계 선택 화면의 「✈ 비행기 바꾸기」로 언제든 바꿀 수 있습니다.
- 각 단계는 시작 직후 **0.8초 동안 준비 시간**이 있어, 소리를 낼 준비를 하는 동안 가운데 높이에서 떠 있습니다.
- **키보드로 하기** → 마이크 없이 <kbd>Space</kbd> 또는 <kbd>↑</kbd> 로 연습할 수 있습니다.
- 구멍마다 놓인 별 ★ 을 모으면 점수가 올라갑니다.
- 화면 위아래 끝에서는 죽지 않습니다. 소리를 내지 않으면 바닥 근처를 낮게 날고, 장애물에 부딪혔을 때만 실패합니다.
- 마이크에서 소리가 전혀 안 잡히면 왼쪽 아래에 「🔇 마이크 소리가 안 들려요」 가 표시됩니다.
- <kbd>R</kbd> 다시 시작 · <kbd>Esc</kbd> 단계 목록

### 조종 설정 (화면 오른쪽 아래)

| 설정 | 설명 |
| --- | --- |
| 소리크기 + 높이 | 볼륨과 음높이를 함께 사용 (기본값) |
| 소리 크기만 | 볼륨만으로 조종 — 목소리 높낮이가 어려운 경우에 적합 |
| 소리 높이만 | 음높이만으로 조종 — 계이름 연습용 |
| 민감도 | 비행기가 너무 위로만 뜨면 왼쪽으로, 잘 안 올라가면 오른쪽으로 |
| 소리 다시 맞추기 | 주변 소음이 달라졌을 때 누르면 기준을 다시 잡습니다 |

## 10단계 구성

| 단계 | 배경 | 특징 |
| --- | --- | --- |
| 1 | 맑은 하늘 | 구멍이 330px로 아주 넓음 |
| 2 | 초원 언덕 | 조금 좁아짐 |
| 3 | 노을 사막 | 더 좁아짐 |
| 4 | 푸른 바다 | **장애물이 위아래로 움직이기 시작** (↕ 표시) |
| 5 | 밤하늘 도시 | 움직임 + 좁은 구멍 |
| 6 | 눈 내리는 산 | 진행 속도 상승 |
| 7 | 신비한 숲 | **떠다니는 블록** 등장 |
| 8 | 용암 동굴 | 빠르고 좁음 |
| 9 | 오로라 극지 | 매우 어려움 |
| 10 | 우주 정거장 | 구멍 186px, 최종 도전 |

단계마다 배경·장애물 색이 바뀌고, 구름 / 모래언덕 / 물방울 / 별 / 눈 / 나무 / 불티 / 오로라 / 행성이 시차(패럴랙스)로 흘러갑니다. 통과한 단계는 브라우저에 저장되어 다음 단계가 열립니다. (「모든 단계 열기」 버튼으로 전체 해제 가능)

## 기술 메모

- 순수 HTML + Canvas + Web Audio API, 외부 라이브러리 없음
- 볼륨은 RMS를 dB로 변환한 뒤, 주변 소음(바닥)과 최근 가장 큰 소리(꼭대기)를 자동으로 추적해 그 사이를 0~1로 정규화 — 마이크 입력 크기나 교실 소음이 달라도 비행기가 한쪽에 붙지 않음
- 단계를 시작할 때마다 준비 시간 동안 주변 소음을 다시 측정해 기준을 잡음
- 음높이는 90~1100Hz 대역의 스펙트럼 무게중심으로 추정하며, 보조 입력으로만 사용(보통보다 높으면 조금 더 위로)
- 소리 크기를 화면 높이에 직접 대응시키고 스프링·감쇠로 부드럽게 따라가게 하여, 소리를 유지하면 그 높이가 유지됨
- 물리 계산은 시간 기반이라 60Hz / 120Hz 등 모니터 주사율과 무관하게 동일한 속도로 동작
- 비행기 5종은 모두 Canvas 경로로 직접 그려 이미지 파일이 필요 없음
- 10개 단계 모두 자동 플레이 시뮬레이션으로 완주 및 별 전부 획득이 가능함을 확인
